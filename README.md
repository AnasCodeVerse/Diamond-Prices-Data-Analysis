## 💎 Diamonds Dataset EDA

Explore the **Diamonds dataset** from [Kaggle](https://www.kaggle.com/datasets/shivam2503/diamonds) to understand how factors like **carat, cut, color, and clarity** affect the **price** of diamonds using Python and data visualization tools.

---

### 📊 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of the Diamonds dataset to uncover hidden insights and patterns. Through a series of visualizations, we examine how each feature relates to the diamond's price and physical characteristics.

---

### 🗂 Dataset Features

The dataset includes over 50,000 observations with the following attributes:

| Feature | Description |
|---------|-------------|
| `carat` | Weight of the diamond (0.2–5.01) |
| `cut`   | Quality of the cut (Fair, Good, Very Good, Premium, Ideal) |
| `color` | Diamond color (from J (worst) to D (best)) |
| `clarity` | Clarity (I1 (worst) to IF (best)) |
| `depth` | Total depth percentage |
| `table` | Width of top of diamond relative to widest point |
| `price` | Price in US dollars |
| `x, y, z` | Dimensions in mm |

---

### 🧰 Tools & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

### 📈 Key Visualizations

- Histogram of **price**
- Scatter plot of **carat vs price**
- Box plots of **price by cut, color, and clarity**
- Heatmap of **correlation matrix**
- Count plots for **categorical features**

---

### 📎 Sample Insights

- Price increases exponentially with carat.
- Premium and Ideal cuts dominate the dataset.
- Color grade D (best) is relatively rare.
- Clarity and cut also influence price, but carat has the strongest correlation.
